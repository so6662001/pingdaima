按 `AGENTS.md` 的「启动协议」开始开发 DevFlow 研发管理平台。

具体做法：

1. 先读 `docs/dev/BUILD-PLAN.md` 与 `docs/dev/TASKS.md`，确定当前批次与第一个未完成任务。
2. 检查并准备环境（Node ≥ 20、pnpm、Docker 起 Postgres 与 Redis）。缺什么自己装，不要问我。
3. 把当前批次的任务登记为待办清单。
4. 逐个任务执行完整闭环：读 PRD 章节与原型页面 → 实现 → 跑 lint / typecheck / test / 校验脚本 → 勾选 `docs/dev/TASKS.md` → 单独提交一个 commit。
5. 批次做完后跑该批次的验收项，输出摘要，然后继续下一批次。
6. 遇到歧义不要停，按 PRD 优先决策，把问题记到 `docs/dev/OPEN-QUESTIONS.md` 后继续。

硬性要求：功能完整、界面与原型 100% 一致、逻辑与算法与指标严格符合 PRD。不许简化、不许臆造、不许留占位实现、不许未验证就说完成。
