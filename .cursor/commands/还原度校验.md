对我指定的页面做高保真还原度校验。

步骤：

1. 起原型静态服务与应用开发服务。
2. 跑 `pnpm e2e:parity -- --grep <页面>`，在 1600×1200 与 1366×768 两档视口对比。
3. 差异超过 1% 时，打开 `e2e/__diff__/` 的差异图，逐处定位原因（缺元素 / 间距 / 颜色 / 字号 / 数据不一致）。
4. 属于实现缺失的直接修复；属于数据差异的检查种子数据是否与原型 fixtures 一致；属于原型已知瑕疵的在 `docs/dev/UI-PARITY.md` 登记豁免并写明理由。
5. 修复后重新校验，直到达标。

同时对照 `.cursor/rules/03-ui-fidelity.mdc` 的「常见还原失误」清单逐条自查。
