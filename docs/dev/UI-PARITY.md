# 高保真还原清单（24 页）

> 配套规则：[`.cursor/rules/03-ui-fidelity.mdc`](../../.cursor/rules/03-ui-fidelity.mdc)。每页列出**必须还原的结构与交互**，遗漏任何一条都算未完成。
>
> 校验方式：`make parity PAGE=<page>`，阈值 `maxDiffPixelRatio ≤ 0.01`，视口 1600×1200 与 1366×768 两档。跑之前先 `make seed`。

## 全局（每页都要具备）

- 侧边栏：五个分组（工作区 / 需求与客户 / 交付管理 / 工程效能 / 组织协同）、当前项高亮、徽标数字、折叠态（宽 60px）并持久化到 `localStorage['df_collapsed']`
- 顶栏：面包屑、全局搜索（`Ctrl+K` 命令面板，含分类结果与图标）、新建按钮、通知铃铛与未读点、用户菜单
- 页头：标题 + 状态标签 + 描述 + 右上操作按钮组
- 通用交互：Toast（成功/错误两态、自动消失）、抽屉（右侧滑入 + 遮罩 + Esc 关闭）、弹窗、Tabs、下拉菜单、开关、复选框、悬浮提示 `.tip[data-tip]`
- 空状态、加载骨架、错误态三件套
- 数字格式：千分位、百分比小数位、环比写法（`+2.4pt` / `环比 −1.8pt`）与原型一致

## 逐页清单

### `index.html` → `/`
研发中心工作台。四张统计卡 + 交付趋势图 + 项目健康列表 + 风险清单 + 客户之声（工单统计与 TOP 需求）+ 待办四页签（待我审批 / 待我评审 / 指派给我 / 抄送我的）+ 快捷入口。页头有「研发看板」按钮直达 `/board`。

### `login.html` → `/login`
左侧品牌区（渐变背景 + 特性列表），右侧登录卡（账号密码 / 企业微信扫码切换、记住我、错误提示态）。

### `mywork.html` → `/mywork`
个人待办五页签（全部 / 待审批 / 待评审 / 指派给我 / 已逾期）+ 我的任务卡片（含子任务勾选清单、进度条、分支与 CI 徽标）+ 企业微信推送状态卡 + 今日日程时间轴 + 我参与的项目。「我的看板」按钮跳 `/board?bd=mine`。

### `board.html` → `/board`　**（最复杂，单独重点对待）**
- 五类看板页签：迭代 / 需求 / 缺陷 / 发布 / 我的，**列定义与卡片字段随类型切换**
- 范围栏：全部 / 按产品线 / 按项目（带迭代下拉）/ 按团队；范围摘要；跨项目提示条；`localStorage['df_board_scope']` 记忆
- 迭代信息条：单项目显示迭代目标与完成度；跨项目显示并行迭代总览表格（可「只看它」下钻）
- 工具条：搜索、四个过滤器（只看我的 / 阻塞 / 超期停留 / CI 失败，**计数随范围动态变化**）、泳道六选一、密度两档、卡片计数、全屏
- 列头：状态点、名称、计数、WIP 徽标（正常/黄/红三态；跨项目时改为项目构成条）、`?` 策略气泡、`+` 新建、`−` 折叠；折叠列竖排文字
- 卡片：类型色条、类型图标、编号、优先级徽标、停留天数色阶徽标、标题、父需求行、徽标区（点数 / 分支 / 提交数 / PR / CI / 评审 / 用例 / 缺陷 / AC / 子任务 / 环境 / 客户 / 技能标签 / 项目色标）、进度条、阻塞斑马纹与原因、拉取信号虚线绿框、底部头像与认领按钮
- WIP 告警条、拖拽（乐观更新 + 越限二次提醒 + 失败回滚）
- 卡片详情抽屉：快捷信息条、属性网格、研发上下文、流转轨迹（含各列停留时长）、子任务、底部三个操作
- 度量抽屉：四统计 + CFD + 周期时间散点（50%/85% 分位线）+ 各列平均停留 + WIP 趋势 + 阻塞 TOP + 健康诊断
- 看板配置弹窗四页签：列与 WIP / 列策略 / 卡片显示 / 自动化流转
- 图例条、深链 `#bd=`、`#scope=`、`#lane=`、`#metrics=1`、`#card=1`

### `requirement.html` → `/requirement`
八页签：需求池（表格含来源渠道/客户呼声/价值/紧迫列）、需求看板（四种分组）、需求分解、阶段排期（三种视图 + 甘特 + 今天标记）、清洗与归档（分诊队列 / 富化建议 / 重复合并 / DoR 达标率 / 归档库）、评审流程（7 节点可点击 + 节点详情 + 价值评审会投票表 + 流程配置弹窗）、优先级模型（因素权重表 / 五种算法切换 / 公式区 / 实时排序预览 / 模型版本）、需求分析。弹窗：推送到项目、智能富化、拆解。深链 `#tab=`、`#tab=board&g=own`、`#tab=sched&sv=ver`、`#tab=model&algo=1`。

### `requirement-detail.html` → `/requirement/:code`
头部（编号 / 标题 / 渠道 / 来源单号 / 客户数 / 状态）+ 阶段排期与进度卡（四个关键日期 + 阶段条 + 今天标记 + 阶段表）+ 六页签（详情 / 子工作项拆解工作台 / 测试与质量 / 代码与发布 / 活动 / 价值与复盘）+ 右侧属性面板。弹窗：拆解、推送到项目。深链 `#REQ-2041`。

### `ticket.html` → `/ticket`
六页签：工单池、工单清洗·分诊（预判置信度 / 六类判定 / 相似聚类 / 批量）、处理看板（按状态 / 渠道 / 客户等级三种分组）、SLA 与时效、反馈分析与转化、服务目录与规则（7 类工单类型表 + 类型配置弹窗）。SLA 剩余量条与超时标红。

### `customer.html` → `/customer`
五页签：客户列表、客户 360 视图、需求呼声矩阵（呼声数 / 等级加权两种排序 + 排名变化）、交付承诺跟踪、上线回访。

### `product.html` → `/product`
四页签：产品全景（产品卡片可点击进详情）、产品路线图（时间轴 / 版本 / 迭代 / 里程碑 / Now-Next-Later 五视角 + 客户反馈抽屉 + 对外同步设置）、版本与发布、产品度量。弹窗：新建/维护产品。

### `product-detail.html` → `/product/:code`
七页签：产品概览、能力与模块、需求与路线图、版本与发布、客户与反馈、产品指标、产品配置。

### `project.html` → `/project`
五页签：项目列表（行可点击进详情）、项目组合甘特（今天线）、迭代总览（每卡含燃尽迷你图 + 「看板」与「进入迭代」两个按钮）、资源排期与容量（成员×周热力矩阵 + 容量日历扣减 + 冲突检测 + 快速排期弹窗）、风险与问题。

### `project-detail.html` → `/project/:code`
七页签：迭代看板、任务池·自助认领、迭代计划（多版本并行规划板 + 拖拽 + 容量告警 + 迭代目标）、计划与甘特、迭代度量、成员与工时、项目文档。深链 `#tab=s7`。

### `agile.html` → `/agile`
五页签：团队迭代总览（多团队节奏甘特）、敏捷仪式（站会看板 + 仪式日历）、规划与估算（规划扑克）、迭代健康（雷达图）、跨团队依赖（依赖图）。

### `testing.html` → `/testing`
六页签：质量概览、用例库、测试计划与执行、缺陷管理、自动化与门禁、漏测分析（六步流水线 + 判定规则表 + 反查匹配方式 + 漏测清单 + 类型分布 + 模块热度 + 趋势）。

### `devops.html` → `/devops`
五页签：代码仓库、Pull Request（详情四页签：概览 / 文件变更 / 评审意见 / CI 检查）、流水线 CI/CD（阶段条 + 日志终端）、环境与部署、代码质量与安全。GitHub App 集成状态展示。

### `worklog.html` → `/worklog`
五页签：我的工时（时间轴 + 推算明细 + 确认操作）、团队工时、工时归集与分摊、采集规则与算法（公式终端块 + 六个参数卡 + 准确度趋势 + 七个采集开关 + 四条数据使用原则）、成本核算。

### `people.html` → `/people`
五页签：人员总览、个人效能画像（六维雷达 + 趋势 + 贡献拆解）、产品贡献率（成员×产品矩阵 + 单点依赖标记）、团队分布与人才识别（产出×质量四象限）、指标口径与治理。

### `metrics.html` → `/metrics`
六页签：交付效率、DORA 指标（四项 + 等级）、交付质量、人效与成本（含进入 `/people` 的入口）、团队对比、效能报告。

### `retro.html` → `/retro`
五页签：复盘列表（可点击进详情）、迭代回顾、需求价值复盘、故障复盘、改进项跟踪。创建复盘弹窗。

### `retro-detail.html` → `/retro/:id`
7 步流程条 + 四页签（回顾看板 / 迭代数据 / 行动项 / 结论与纪要）+ 三种模板切换 + 匿名反馈 + 投票 + SMART 校验。

### `notify.html` → `/notify`
五页签：推送规则（24 条规则表）、消息模板（企业微信卡片预览）、推送记录、订阅与免打扰、推送效果。企业微信集成状态卡。

### `wiki.html` → `/wiki`
左侧空间树 + 文档列表 + 文档详情（正文 / 评论 / 版本）+ 右侧「最近更新 / 热门文档 / 知识贡献榜」+ 可见范围三选一（空间成员可见 / 全中心可见 / 指定人员）。

### `portal.html` → `/portal`
业务方门户（**独立只读身份**）：我提交的工单（全部 / 研发中 / 待我确认 / 已上线四态）、服务时效承诺、常见问题自助、产品路线图（你的诉求在路线图中的位置 / Now-Next-Later / 标记用户提交的特性）、近期版本发布计划、已发布版本、提交诉求表单（紧迫度三选一）。深链 `#p=v5`。

### `settings.html` → `/settings`
六页签：集成中心（GitHub App / 企业微信 / 日历 / 监控）、成员与权限（成员表 + 角色权限矩阵 10×5 + 状态操作权限表）、工作流配置（**按工作项类型切换的状态机图** + 工作项类型与颗粒度表）、字段与模板、自动化规则、组织与安全（脱敏、导出审批、审计）。
