# DevFlow · 研发管理平台高保真原型

面向软件公司研发中心的一体化研发管理系统（对标 PingCode / Jira + Confluence + 效能度量）高保真 HTML 原型。
覆盖 **需求管理、产品管理、项目管理、测试管理、代码与 CI（GitHub 集成）、效能度量、知识库** 七大模块，
以「星链数科研发中心」为虚构业务场景，数据、流程、指标口径均按真实研发组织的运作方式设计。

原型为**纯静态页面**，零依赖、零构建，双击 `index.html` 即可在浏览器中完整体验（含图表、拖拽、抽屉、弹窗、命令面板）。

---

## 一、快速预览

```bash
# 方式一：直接打开
open index.html          # macOS
start index.html         # Windows

# 方式二：本地起服务（推荐，避免个别浏览器的本地文件限制）
python3 -m http.server 8088
# 浏览器访问 http://localhost:8088/index.html
```

演示入口：`login.html`（登录页）→ `index.html`（工作台）。

**建议体验路径**：工作台 → 需求管理（需求池 / 看板 / 评审流程 / 需求分析）→ 需求详情 →
项目管理（组合甘特 / 迭代总览）→ 项目详情（迭代看板 / 燃尽图 / CFD）→ 测试管理（用例 / 计划 / 缺陷）→
代码与 CI（仓库 / PR / 流水线 / 部署）→ 效能度量（DORA / 效能报告）→ 知识库 → 系统设置（GitHub 集成）。

小技巧：
- `Ctrl / Cmd + K` 打开全局命令面板（跨模块搜索需求、项目、PR、文档）
- 看板卡片可**拖拽换列**，列头数量实时更新
- 表格行、卡片可点击打开**详情抽屉**；顶栏「新建」可快捷创建各类对象
- 页面 URL 支持 `#tab=xxx` 深链，例如 `product.html#tab=p2` 直接打开产品路线图

## 三、业务设计要点

### 1. 需求管理：价值驱动的分级评审
- **统一入口**：客户反馈 / 内部规划 / 监管合规 / 数据洞察 / 竞品对标五类来源统一进池。
- **价值量化**：RICE 评分（Reach / Impact / Confidence / Effort）自动排序，配「价值—成本四象限」辅助取舍。
- **分级评审**：P0/P1 走「产品初审 → 架构评审 → 价值评审会 → 排期 → 立项」完整链路，P2 及以下由产品线自决。
- **需求分解**：业务主题（Epic）→ 需求 → 用户故事 → 任务，四级分解树与进度自动汇总。
- **就绪度门禁（DoR）**：验收标准、RICE、技术方案、依赖识别齐备才允许排期。

### 2. 产品管理：路线图与版本发布
- 产品全景（阶段、版本、健康度、业务 KPI、SLA）与**能力成熟度矩阵**。
- 年度路线图甘特：按产品线 × 季度展示举措与里程碑，标注今日线。
- 版本管理：版本内容、就绪度检查清单、发布记录与回滚，发布准入与质量门禁联动。

### 3. 项目管理：组合视图 + 敏捷执行
- 项目组合甘特、健康度（健康 / 关注 / 风险）、预算消耗、风险登记册（等级 / 应对 / 责任人 / 截止）。
- 迭代执行：看板（含 WIP 限制与拖拽流转）、Backlog 规划与容量匹配、燃尽图、累积流图（识别瓶颈）、迭代速率。
- 资源与工时：团队负载 / 容量、成员负载率预警（过载 / 饱和 / 正常 / 空闲）、工时结构。

### 4. 测试管理：用例资产到质量门禁
- 用例库按产品 → 模块分层，标注自动化状态与最近执行结果。
- 测试计划 → 执行轮次 → 用例结果 → 缺陷，链路完整可追溯。
- 缺陷管理：严重程度、发现环境、根因分类、SLA 超时预警、生命周期分布、缺陷燃尽。
- **质量门禁**：提交 / 合并 / 提测 / 发布四道门禁，未达标阻断发布并支持豁免审批。

### 5. GitHub 集成与 CI/CD
- GitHub App 接入组织，订阅 `push / pull_request / workflow_run / check_run / release` 等事件。
- **双向智能关联**：提交信息 `[REQ-2041]`、分支名 `feature/REQ-xxxx` 自动关联工作项；PR 创建 / 合并自动流转需求状态；CI 失败自动在工作项下评论并 @ 提交人。
- 流水线：阶段视图 + 实时日志 + 失败重跑 + 制品下载；环境（DEV/TEST/STAGING/PROD）与部署记录、蓝绿 / 灰度 / 回滚策略。
- 代码质量：覆盖率趋势、静态扫描、技术债、提交活跃度热力图、贡献者排行。

### 6. 效能度量：四层指标体系
| 层级 | 指标 |
| --- | --- |
| 交付效率 | 需求交付周期（含等待分解）、吞吐量、按时交付率、WIP、流动效率 |
| 交付质量 | 缺陷密度、缺陷逃逸率、一次通过率、线上故障与 MTTR |
| 交付能力 | DORA：部署频率、变更前置时间、变更失败率、服务恢复时间（含行业对标） |
| 组织人效 | 人均交付、有效投入率、故事点成本、负载与加班健康预警 |

度量口径遵循「**用于发现系统性瓶颈，而非考核个人**」原则，效能报告支持 AI 自动生成结论与改进举措。

### 7. 知识库
空间 → 目录 → 页面三级结构，支持模板、版本、审批、评论、目录导航、权限与复审周期；与需求 / 项目 / 缺陷双向关联。

## 四、设计系统

- **视觉基调**：深色导航 + 浅色内容区，品牌主色 `#2b5cff`，语义色（成功 / 警告 / 危险 / 信息 / 紫 / 青）成体系。
- **信息密度**：13px 基准字号、8px 栅格、紧凑表格，面向重度使用者的高密度专业 SaaS 布局。
- **组件库**：按钮 / 标签 / 徽章 / 表格 / 卡片 / 指标卡 / 看板 / 甘特 / 时间线 / 抽屉 / 弹窗 / 表单 / 流水线 / 终端 / Diff / 文档排版等 40+ 组件，全部定义在 `assets/css/app.css`。
- **图表引擎**：`assets/js/charts.js` 自研轻量 SVG 图表（折线 / 面积 / 柱状 / 堆叠 / 横向条 / 环形 / 仪表 / 雷达 / 热力 / 迷你图 / 燃尽 / 累积流），支持响应式重绘与 hover 提示，无任何第三方依赖。
- **图标**：`assets/js/icons.js` 内置 100+ Lucide 风格线性图标，`<span data-icon="bulb"></span>` 占位自动注入。

## 六、从原型到产品的落地建议

1. **技术选型**：前端 React/Vue + TypeScript + 组件库（可直接复用本原型的 Design Token）；图表切换为 ECharts；后端建议领域拆分为 `需求域 / 项目域 / 测试域 / 集成域 / 度量域`。
2. **数据模型**：以「工作项（WorkItem）」为统一抽象，通过类型（需求 / 故事 / 任务 / 缺陷 / 用例）+ 可配置字段 + 可配置状态机实现多形态，避免为每类对象建独立模型。
3. **集成优先级**：GitHub（代码 / PR / Actions）→ 制品与部署 → 监控告警 → IM 通知 → 历史系统（Jira/TAPD）数据迁移。
4. **度量落地**：先打通事件采集（工作项状态变更、Git 事件、流水线事件、部署事件），再构建指标口径层，最后做可视化，避免口径不一致导致数据不被信任。
5. **推行节奏**：单产品线试点（建议支付网关）→ 固化流程模板与门禁 → 全中心推广 → 度量驱动持续改进。
